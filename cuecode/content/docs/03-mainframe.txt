%%doc mainframe
%%title Mainframe
%%area mainframe
%%aka z/OS, IBM Z, big iron
%%simple A very large, very reliable computer. Banks, airlines and governments run on them.
%%like A freight train. Not the fastest off the line, but it moves everything, all day, without stopping.
%%more z/OS is the main operating system. It's built for huge volumes of work, and for never going down.
%%link IBM z/OS docs | https://www.ibm.com/docs/en/zos

%%doc batch-online
%%title Batch and online
%%area mainframe
%%aka batch job, overnight, OLTP, transaction
%%simple Batch is big work done in bulk with nobody watching. Online is small work done live for a person.
%%like Batch is a laundry service. Online is a coffee counter.
%%more Banks take payments online all day, then run batch overnight to settle everything.
%%see run

%%doc jcl
%%title JCL
%%area mainframe
%%aka Job Control Language, JOB, EXEC, DD
%%simple The instructions that tell z/OS which programs to run and which files to give them.
%%like A work order pinned to a job: which machine, which materials, where the result goes.
%%more Three main statements: `JOB` starts it, `EXEC` runs a program, `DD` connects a file.
%%see run
%%example jcl
//MYJOB    JOB (ACCT),'REPORT',CLASS=A,MSGCLASS=X
//STEP1    EXEC PGM=REPORT1
//INPUT    DD DSN=PROD.SALES.DAILY,DISP=SHR
//OUTPUT   DD SYSOUT=*
%%link IBM JCL reference | https://www.ibm.com/docs/en/zos/latest?topic=mvs-zos-jcl-reference

%%doc dd-statement
%%title DD statement
%%area mainframe
%%aka DDNAME, DISP, ASSIGN
%%simple A JCL line that connects a nickname in your program to a real dataset.
%%like A label on a plug socket. The program plugs in to `INPUT`, and JCL says what's wired behind it.
%%more `DISP=SHR` means read and share. `DISP=OLD` means I need it alone. `DISP=(NEW,CATLG)` means create it and record it.
%%see files

%%doc dataset
%%title Dataset
%%area mainframe
%%aka DSN, sequential file, QSAM, LRECL, RECFM
%%simple The mainframe word for a file. It's made of fixed-size records, not lines.
%%like A deck of cards, all exactly the same size.
%%more `LRECL` is the record length, often 80 from punched cards. `RECFM=FB` means fixed length, blocked. Names look like `PROD.CUST.MASTER`.
%%see files

%%doc pds
%%title PDS
%%area mainframe
%%aka PDSE, partitioned dataset, member, library
%%simple A dataset that holds many small members. It works like a folder.
%%like A folder of documents, stored as one big file.
%%more Your COBOL source, copybooks and JCL all usually live in these.

%%doc vsam
%%title VSAM
%%area mainframe
%%aka KSDS, ESDS, RRDS, IDCAMS, indexed file
%%simple A file you can jump into by key, instead of reading from the top.
%%like A book with an index, rather than a scroll.
%%more A KSDS is keyed, the one you'll use most. Set one up with the IDCAMS utility.
%%see maps
%%link IBM VSAM guide | https://www.ibm.com/docs/en/zos/latest?topic=dfsms-zos-using-data-sets

%%doc pic-clause
%%title PIC clause
%%area mainframe
%%aka PICTURE, PIC X, PIC 9, V, S, Z
%%simple A template that says exactly what a COBOL field holds, one character at a time.
%%like A form with one box per letter.
%%more `X` any character, `9` a digit, `V` an invisible decimal point, `S` a sign, `Z` a digit that shows as a space when it's a leading zero.
%%see variables
%%example cobol
       01  WS-NAME    PIC X(20).
       01  WS-TOTAL   PIC S9(7)V99.
       01  WS-OUT     PIC ZZZ,ZZ9.99.

%%doc level-number
%%title Level numbers
%%area mainframe
%%aka 01, 05, 77, 88
%%simple The numbers in front of COBOL fields that show what sits inside what.
%%like Outline numbering: a heading, with sub-points under it.
%%more `01` is a whole record. Higher numbers go inside it. `88` isn't a field: it names a value.
%%see records

%%doc group-item
%%title Group item
%%area mainframe
%%aka record, elementary item, REDEFINES
%%simple A COBOL field made up of smaller fields.
%%like An address, made up of street, city and postcode.
%%more Moving a group copies its bytes as one chunk, with no conversions. `REDEFINES` lets you view the same bytes a second way.
%%see records

%%doc 88-level
%%title 88 level
%%area mainframe
%%aka condition name, SET TO TRUE
%%simple A name for a value of a field, so your code reads like English.
%%like Naming a switch position: "on" instead of "1".
%%see missing
%%example cobol
       01  WS-STATUS   PIC X.
           88  ACTIVE  VALUE "A".
           88  CLOSED  VALUE "C".

%%doc comp-3
%%title Packed decimal
%%area mainframe
%%aka COMP-3, COMP, binary, zoned decimal
%%simple A compact, exact way to store numbers: two digits per byte, with a sign at the end.
%%like Writing money in a ledger, not estimating it.
%%more `COMP-3` is the usual choice for money. `COMP` is binary, used for counters. Plain `PIC 9` is zoned: one byte per digit.
%%see numbers

%%doc copybook
%%title Copybook
%%area mainframe
%%aka COPY, member, record layout
%%simple A shared piece of COBOL, usually a record layout, that programs pull in with `COPY`.
%%like A standard form template that every department uses.
%%more Change a copybook and every program using it needs recompiling.
%%see modules

%%doc paragraph
%%title Paragraph
%%area mainframe
%%aka PERFORM, section, GO TO
%%simple A named block of COBOL that you run with `PERFORM`.
%%like A function with no inputs, sharing all the same memory.
%%see functions

%%doc call-subprogram
%%title CALL and LINKAGE
%%area mainframe
%%aka subprogram, USING, LINKAGE SECTION
%%simple How one COBOL program runs another, passing data by sharing memory.
%%like Lending a colleague your notebook. Whatever they write in it, you'll see.
%%see functions
%%example cobol
           CALL "TAXCALC" USING WS-PRICE WS-TAX.

%%doc ebcdic
%%title EBCDIC
%%area mainframe
%%aka ASCII, code page
%%simple The mainframe's character encoding. It's different from the ASCII used everywhere else.
%%like Two alphabets with the same letters in a different order.
%%more In EBCDIC, letters sort before digits, and lowercase before uppercase. In ASCII, it's the other way round. That catches people out in file transfers.

%%doc abend
%%title ABEND
%%area mainframe
%%aka abnormal end, S0C7, S0C4, S322, S806, crash
%%simple A job or program crashing on a mainframe.
%%like The job falling over, with a code saying why.
%%more S0C7: bad data in a number field. S0C4: illegal memory access. S322: ran out of CPU time. S806: program not found.
%%see errors

%%doc return-code
%%title Return code
%%area mainframe
%%aka RC, COND, condition code, MAXCC, IF THEN
%%simple A number each step leaves behind: 0 is fine, 4 is a warning, 8 and up means problems.
%%like A traffic light at the end of each step.
%%more JCL uses it to decide what runs next. Set it from COBOL with `MOVE 8 TO RETURN-CODE`.

%%doc file-status
%%title FILE STATUS
%%area mainframe
%%aka 00, 10, 23, 35
%%simple A two-character code your program checks after each file action.
%%like A note saying how the last errand went.
%%more `00` fine, `10` end of file, `23` record not found, `35` file not found.
%%see files
