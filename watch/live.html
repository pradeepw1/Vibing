    Setup and help

    On this Mac

    1. Keep the Terminal window with the watcher open.
    2. System Settings → Network → Wi-Fi → Details… → Proxies → turn on Automatic proxy configuration → URL: http://127.0.0.1:8899/proxy.pac → OK. Or start the watcher with --setup and it does this for you.
    3. Quit and reopen Chrome and Brave if they were open.
    4. When you’re done: press Ctrl+C in Terminal and turn that switch off again (with --setup it switches off by itself).

    On your iPhone

    1. Start the watcher with --phone. Terminal shows an address like http://192.168.1.20:8899/proxy.pac.
    2. On the iPhone: Settings → Wi-Fi → tap ⓘ next to your network → Configure Proxy → Automatic → paste that address → Save.
    3. Phone traffic shows up under “Phone”. Switch Configure Proxy back to Off when you’re done.

    If something looks wrong

    • Nothing shows up. Check the proxy address is exactly right, then quit and reopen the browser.
    • Safari shows nothing but Chrome does. iCloud Private Relay may be sending Safari’s traffic around the watcher. Turn it off while you test (Settings → your name → iCloud → Private Relay).
    • Lots of “Other apps”. Other Mac apps use the same setting. Pick a browser above to hide them.
    • Pages stop loading. If the watcher stops while the setting is on, browsers should go direct. If they don’t, turn the setting off, or run python3 watch/watch.py --off.
    • “Browser maker” means the company that makes the browser you’re looking at, e.g. Google for Chrome. Searching on google.com in Chrome counts there too, because the watcher can’t see what was sent.
    • Trackers are matched against a built-in list of about 140 ad and analytics companies, plus servers whose names show they swap ad IDs (like sync. or match.). Anything else shows as a website, so the real number can be higher.

    Nothing is stored. Closing the watcher forgets everything unless you saved a spreadsheet.

    The watcher runs only on your Mac and sends nothing anywhere.
